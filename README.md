
# Zijing Daily

Static daily intelligence briefing generated by Hermes.

## Historical records

Every issue is preserved twice:
- `archive/YYYY-MM-DD.html` — human-readable snapshot
- `data/archive/YYYY-MM-DD.json` — structured source-of-truth for future analysis

Git history provides an additional audit/rollback layer.

## Local render

```bash
python3 render.py
```

## Publish

```bash
./publish.sh
```

## GitHub Pages

Repository Settings → Pages → Source: GitHub Actions.

Expected project URL:

`https://zinnliu233.github.io/daily-news/`

## Privacy

The published site is public. Never write private memory, chats, credentials, company-confidential information, or private action items into `data/latest.json`.
